# MoneyGraph — рабочее место AML-аналитика

Веб-приложение для восстановления финансовой структуры группы по графу переводов. Аналитик загружает выгрузку
(три parquet-файла или zip), сервер присваивает каждому узлу роль с числовым обоснованием, кластеризует сеть и
ранжирует узлы для проверки. Дальше аналитик работает с графом, карточками узлов, ассистентом и выгрузками CSV.

> Роли — **гипотезы для проверки**, а не утверждение о виновности. Данные обезличены; по умолчанию они не покидают
> сервер (LLM-ассистент выключен).

## Запуск

Проще всего — в один клик: `start-windows.bat`, `start-macos.command` или `start-linux.sh` в корне репозитория
(см. [`../LAUNCH.md`](../LAUNCH.md)). Вручную:

```bash
cp .env.example .env            # обязательно; внутри — токен доступа, лимиты, LLM
docker compose up --build       # http://localhost:8080
```
При первом старте создаётся демо-прогон на данных HackAlem (2 248 узлов), он считается за несколько секунд.
По умолчанию интерфейс доступен только с этой машины (`MG_HTTP_BIND=127.0.0.1`). Чтобы открыть его другим
компьютерам, задайте `MG_HTTP_BIND=0.0.0.0` и обязательно `MG_API_TOKEN`.

Разработка без Docker:
```bash
cd backend && uv run uvicorn mg_api.app:create_app --factory --reload    # API на :8000
cd frontend && npm ci && npm run dev                                     # UI на :5173, /api → :8000
```

## Что умеет
- **Прогоны:** загрузка zip или трёх parquet-файлов с параметрами сбора (окно наблюдения, глубина обхода,
  порог суммы; если не заданы — выводятся из данных с предупреждением). Прогресс по стадиям, отмена, повтор,
  удаление. Ошибки данных приходят с указанием поля.
- **Анализ:** роли (координатор, консолидатор, распределитель, транзит, конечный получатель, периферия) по явным
  правилам с порогами; приоритет = сумма восьми компонент × надёжность; кластеры с гипотезами; устойчивость сети;
  список данных для дозагрузки.
- **Граф:** обзор с фильтрами, соседство, «откуда деньги» / «куда ушли», путь между узлами. Все ответы ограничены
  по размеру и сообщают об усечении.
- **Карточка узла:** обоснование, метрики с единицами, вклад компонент в приоритет, выполненные правила,
  контрагенты и транзакции с пагинацией.
- **Ассистент:** шаблонные вопросы на русском работают офлайн. LLM-режим (Claude) включается только через
  `MG_LLM_ENABLED=true` и ключ API.
- **Выгрузки:** `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`, признаки, устойчивость, запросы данных, отчёт
  и всё одним архивом.

## Доступ
Если задан `MG_API_TOKEN`, интерфейс один раз спросит токен и сохранит HttpOnly-cookie сессии. Скрипты передают
`Authorization: Bearer <токен>`. Без токена API открыто — так можно работать только в доверенной сети.

## API
Версионированное REST API под `/api/v1`; контракт — `docs/API.md`, схема OpenAPI — `/api/v1/openapi.json` (нужна
авторизация). Все ошибки приходят в едином конверте `{"error": {code, message, request_id, details, retryable}}`.

## Эксплуатация
- Данные и результаты прогонов лежат в томе `moneygraph-data`; `docker compose down` их не удаляет.
- `/api/v1/health` — жив ли процесс, `/api/v1/ready` — готов ли сервис (БД, запись на диск, планировщик прогонов).
- Логи — JSON в stdout, у каждой строки `request_id`; тот же id приходит клиенту в заголовке `X-Request-ID`.
- Память ограничивают `MG_MAX_DECODED_MB` и `MG_MAX_TRACE_CELLS`: слишком большие выгрузки отклоняются по
  метаданным parquet ещё до распаковки. Каждый прогон идёт в отдельном процессе с бюджетом `MG_RUN_MEMORY_MB`,
  который проверяется периодически: прогон сверх бюджета останавливается с понятной ошибкой. Жёсткий предел всего
  контейнера — `MG_BACKEND_MEMORY`; при его превышении ядро в первую очередь останавливает процесс прогона, но API
  расходует тот же предел, так что гарантии для API нет. Держите `MG_WORKERS × MG_RUN_MEMORY_MB` + ~1,5 ГБ
  в пределах `MG_BACKEND_MEMORY`.
- Обновление: остановите старую версию backend перед запуском новой (`docker compose up --build` так и делает).
  Две версии не должны одновременно обрабатывать прогоны из одного тома данных.
- HTTPS терминируйте перед контейнером `frontend` и включите `MG_COOKIE_SECURE=true`. Backend запускается одним
  процессом uvicorn: счётчик попыток входа хранится в памяти процесса, а параллелизм расчётов задаёт `MG_WORKERS`.

## Качество
```bash
cd backend && uv run --group dev pytest && uv run ruff check . && uv run ruff format --check .
cd frontend && npm run check
cd frontend && PLAYWRIGHT_BROWSERS_PATH=.browsers npx playwright install chromium && \
  PLAYWRIGHT_BROWSERS_PATH=.browsers npm run test:e2e
```
После изменения API: `cd backend && uv run python tools/export_contract.py` пересобирает `openapi.json` и
фикстуры фронтенда из реального прогона.
