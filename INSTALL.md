# Установка и запуск

Проект лёгкий: нужен только **uv**, менеджер Python-окружений. Python ставить не нужно — uv сам
скачает Python 3.12 и все пакеты. Node.js, база данных, Docker и GPU не нужны.

## Что понадобится

| | |
|---|---|
| ОС | Linux, macOS или Windows |
| Программы | [uv](https://docs.astral.sh/uv/) (ставится одной командой, скрипт делает это сам) |
| Интернет | только при первой установке (~450 МБ пакетов в папку `.venv`) и для AI-ассистента |
| Браузер | Chrome, Edge, Firefox или Safari с включённым WebGL (аппаратное ускорение) |
| Необязательно | ключ OpenAI — для свободных вопросов AI-ассистенту |

Полный пересчёт занимает около 10 секунд на обычном ноутбуке.

## Быстрая установка: Linux и macOS

```bash
git clone git@github.com:BAITC-Hacks/hack-7ab49ed7-a-ln.git
cd hack-7ab49ed7-a-ln
git checkout Alikhan-branch
./install.sh
```

Скрипт делает всё по порядку:

1. ставит uv, если его нет;
2. ставит Python 3.12 и зависимости точных версий из `uv.lock`;
3. создаёт `.env` из `.env.example` (если передан ключ OpenAI — записывает его туда);
4. пересчитывает все выгрузки в `out/` и проверяет их по схеме ТЗ;
5. печатает, как открыть экран.

| Команда | Что делает |
|---|---|
| `./install.sh` | установка и пересчёт |
| `./install.sh --serve` | то же и сразу запускает экран с AI-ассистентом |
| `./install.sh --test` | то же и прогоняет автотесты |
| `./install.sh --no-run` | только установка зависимостей |
| `OPENAI_API_KEY=sk-... ./install.sh` | то же и записывает ключ в `.env` |

Скрипт можно запускать повторно: уже установленное он не трогает, а существующий `.env` не перезаписывает.

## Установка вручную (любая ОС, включая Windows)

**1. Поставьте uv.**

Linux и macOS:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

После установки откройте новый терминал, чтобы команда `uv` стала доступна.

**2. Поставьте зависимости** в папке проекта:

```bash
uv sync
```

**3. Пересчитайте выгрузки:**

```bash
uv run moneygraph
```

В конце должно быть «проверка схемы ТЗ: OK».

**4. Откройте экран** — один из двух способов:

- **без сервера:** откройте файл `out/viewer.html` в браузере двойным кликом. Работает без интернета:
  схема, очередь проверки, карточки, фильтры, страницы «Как считается…» и вопросы по графу;
- **с AI-ассистентом:** `uv run moneygraph serve`, затем откройте <http://127.0.0.1:8765>. Остановить —
  Ctrl+C. Другой порт: `uv run moneygraph serve --port 8800`.

## AI-ассистент

Ассистенту нужен ключ OpenAI. Скопируйте `.env.example` в `.env` (скрипт делает это сам) и впишите ключ:

```bash
OPENAI_API_KEY=sk-...
# OPENAI_BASE_URL=https://...   # если ключ выдан через прокси
# OPENAI_MODEL=gpt-5.4-mini     # если нужна конкретная модель; иначе выбирается автоматически
```

После изменения `.env` перезапустите `uv run moneygraph serve`. Файл `.env` в git не попадает.

Без ключа всё остальное работает: вопросы о путях, источниках денег, общих получателях и кластерах
считаются прямо по графу, без сети.

## Проверка

```bash
uv run pytest
```

Ожидается «7 passed». Тесты заново пересчитывают выгрузки во временную папку и проверяют:

- схему ТЗ;
- что у каждого клиента есть обоснование с числами;
- обработку 4-го колена;
- что в коде нет захардкоженных gid.

## Все команды

| Команда | Что делает |
|---|---|
| `uv run moneygraph` | полный пересчёт: `data/*.parquet` → `out/` |
| `uv run moneygraph --data путь --out путь` | то же с другими папками |
| `uv run moneygraph serve` | экран и AI-ассистент на <http://127.0.0.1:8765> |
| `uv run moneygraph explain 8165763100` | карточка клиента в терминале (полный номер или последние цифры) |
| `uv run pytest` | автотесты |

## Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| `uv: command not found` сразу после установки uv | откройте новый терминал или выполните `source $HOME/.local/bin/env` |
| `uv sync` не может скачать пакеты | проверьте интернет; за корпоративным прокси задайте `HTTPS_PROXY=http://прокси:порт` |
| `Address already in use` при `serve` | порт занят: `uv run moneygraph serve --port 8800` |
| На экране нет схемы, есть сообщение про WebGL | включите аппаратное ускорение в настройках браузера; очередь, карточки и ассистент работают и без схемы |
| Ассистент пишет «LLM недоступен» | проверьте ключ в `.env` и перезапустите `serve`; при прокси — `OPENAI_BASE_URL` |
| После обновления кода что-то сломалось | переустановите окружение: `rm -rf .venv && uv sync` |

## Удаление

Всё окружение лежит в папке проекта (`.venv`). Удалите папку проекта. Если нужно, очистите кэш uv:
`uv cache clean`.
