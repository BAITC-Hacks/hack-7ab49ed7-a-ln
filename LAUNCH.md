# Запуск в один клик

Инструкция для жюри и всех, кто хочет посмотреть MoneyGraph на данных кейса. Нужен только Docker; Python, Node.js
и другие инструменты ставить не нужно.

## 1. Установите Docker (один раз)

| Система | Что установить |
|---|---|
| Windows 10/11 | [Docker Desktop](https://www.docker.com/products/docker-desktop/). Установщик включит WSL 2; может понадобиться перезагрузка |
| macOS | [Docker Desktop](https://www.docker.com/products/docker-desktop/) для своего процессора (Apple Silicon или Intel) |
| Linux | [Docker Engine](https://docs.docker.com/engine/install/) с плагином Compose (команда `docker compose`) |

После установки откройте Docker Desktop один раз и примите условия использования. Если позже Docker окажется
выключен, скрипт запуска включит его сам.

## 2. Скачайте проект

`git clone <адрес репозитория>` или на GitHub «Code → Download ZIP». Архив нужно **распаковать**: изнутри
нераспакованного архива скрипт не запустится.

## 3. Запустите

| Система | Что сделать |
|---|---|
| Windows | дважды щёлкните `start-windows.bat` |
| macOS | дважды щёлкните `start-macos.command` |
| Linux | в терминале из папки проекта выполните `./start-linux.sh` (или дважды щёлкните файл, если файловый менеджер разрешает запускать скрипты) |

## 4. Что происходит дальше

1. Скрипт проверяет Docker и при необходимости запускает его.
2. Собирает и запускает приложение. **Первый запуск занимает несколько минут** (обычно 3–10, нужен интернет):
   скачиваются образы и зависимости. Следующие запуски занимают секунды.
3. Приложение само анализирует данные кейса: 2 248 клиентов, 3 119 связей, 4 840 переводов за июль 2026. В окне
   скрипта видны стадии анализа; сам расчёт занимает около 10 секунд.
4. Выгрузки сохраняются в папку `results/` в корне проекта: `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`,
   а также `features.csv`, `resilience.csv`, `data_requests.csv` и `run_report.md`.
5. В браузере открывается рабочее пространство с результатом: граф, топ-лист приоритетов, карточки клиентов,
   ассистент.

Приложение работает, пока открыто окно скрипта. Чтобы остановить его, нажмите Enter в этом окне. Результаты
сохраняются: при следующем запуске анализ не повторяется, и результат открывается сразу.

## Что посмотреть за 5 минут

1. **Топ-лист** слева — клиенты по приоритету проверки; у каждого есть блок «Почему проверить».
2. Щёлкните клиента № 1, откроется **карточка**: роль, основание гипотезы с числами, вклад компонент приоритета,
   сработавшие правила, контрагенты и переводы.
3. Кнопки **«← Откуда деньги»** и **«Куда ушли →»** показывают цепочки переводов на графе.
4. Вкладка **Помощник**: например, «топ 5 консолидаторов» или «почему 115284100».
5. Вкладка **Обзор** — сводка ролей, устойчивость сети, качество модели. **Методология** — правила ролей и пороги.

## Если что-то пошло не так

| Сообщение или ситуация | Что сделать |
|---|---|
| «Docker не найден» | установите Docker (шаг 1) и запустите файл снова |
| «Docker не ответил за 3 минуты» | дождитесь, пока Docker Desktop полностью запустится, и запустите файл снова |
| Windows предупреждает, что файл скачан из интернета | «Подробнее» → «Выполнить в любом случае» (или «Запустить») |
| macOS: «не удаётся проверить разработчика» | правый щелчок по файлу → «Открыть» → «Открыть». На macOS 15 и новее: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Другой путь — в Терминале из папки проекта выполнить `bash start-macos.command` |
| macOS спрашивает доступ Терминала к папке | нажмите «Разрешить» |
| macOS или Linux: «Permission denied» | в терминале из папки проекта выполните `bash start-macos.command` или `bash start-linux.sh` |
| Linux: Docker требует права администратора | скрипт сам выполнит команды Docker через `sudo` и спросит пароль |
| «Порты 8080–8099 заняты» | закройте программу, которая заняла порт 8080, и запустите файл снова |
| «Не удалось запустить контейнеры» | проверьте интернет и свободное место на диске (нужно около 3 ГБ), затем запустите файл снова |
| Браузер не открылся | откройте адрес из строки «Готово» в окне скрипта |
| Окно закрыли, а приложение продолжает работать | запустите файл снова и нажмите Enter, или выполните `docker compose down` в папке `app` |

Приложение доступно только с этого компьютера. Данные хранятся в томе Docker `moneygraph-data`; удалить их вместе
с приложением можно командой `docker compose down -v` в папке `app`.

## Без скрипта

```bash
cd app
cp .env.example .env
docker compose up --build
```

Затем откройте http://localhost:8080: исследование «Демо: HackAlem, июль 2026» появится в списке.
