# Граф денег — HackAlem AI (команда A-lN)

Инструмент для AML-аналитика: по графу внутрибанковских переводов определяет роли участников
(консолидатор, транзит, распределитель, конечный получатель, координатор, периферия), кластеры и
приоритет проверки — «кого из 2 248 клиентов смотреть первым и почему».

> Работа в процессе — README будет дополнен.

```bash
uv sync
uv run moneygraph          # parquet из data/ → выгрузки в out/
```
